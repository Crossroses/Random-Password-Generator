# Random-Password-Generator
GUI-приложение «Random Password Generator» с возможностью настройки параметров пароля, сохранением истории и Git.
# Random Password Generator

**Автор:** Коноплёва Влада
**Описание:** Простое и удобное GUI-приложение на Python для генерации случайных паролей с гибкой настройкой параметров.
**Технологии:** Python (стандартная библиотека), Tkinter.
**Функции:**
- Настройка длины пароля (от 4 до 32 символов).
- Выбор типов символов: цифры, буквы (верхний/нижний регистр), спецсимволы.
- Генерация пароля одной кнопкой.
- История с сохранением в JSON.
- Проверка корректности ввода.
